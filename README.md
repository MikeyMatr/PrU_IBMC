# Resident API & Dispatcher System (Личный кабинет ЖЭУ / ЖКХ)

Веб-приложение и REST API для автоматизации обработки заявок жителей многоквартирных домов и взаимодействия с диспетчерской службой ЖЭУ.

Проект разработан в рамках производственной практики.

---

## 📌 Функционал системы

* **Ролевая авторизация (RBAC):**
  * **Житель (`resident`):** регистрация, оформление заявок на вызов мастера (сантехник/электрик), отслеживание статусов, просмотр общедомовых новостей.
  * **Мастера и Диспетчеры (`staff`):** доступ к панели управления, фильтрация заявок по категориям, смена статусов, просмотр сводной аналитики за день, публикация новостей.
* **Тикет-система заявок:**
  * Управление статусами: `Новая (new)` ➔ `В работе (in_progress)` ➔ `Завершена (completed)`.
* **Событийная модель (Django Signals):**
  * Отправка Push-уведомлений жителю через Firebase при изменении статуса заявки.
  * Массовая рассылка уведомлений всем жильцам при публикации важной новости.
  * Автоматическое создание расширенного профиля пользователя (`Profile`) при регистрации.

---

## 🛠 Стек технологий

* **Backend:** Python, Django, Django REST Framework (DRF)
* **База данных:** PostgreSQL (`psycopg2-binary`)
* **Аутентификация:** JWT (`djangorestframework-simplejwt`, `PyJWT`)
* **Интеграции:** Firebase Push Notifications (`requests`), CORS (`django-cors-headers`)
* **Конфигурация:** `python-dotenv`
* **Frontend:** HTML5, CSS3, Vanilla JavaScript (Fetch API, LocalStorage)
* **Архитектурный анализ:** UML Use Case Diagram (`Use-Case-Diargam_Kononov.pdf`)

## 🔌 Основные эндпоинты API

* `POST /api/auth/register/` — Регистрация жителя с адресом и квартирой
* `POST /api/auth/login/` — Авторизация (выдача JWT access/refresh токенов и роли)
* `POST /api/auth/refresh/` — Обновление JWT-токена
* `GET /api/pleas/` — Список заявок (с фильтрацией по правам доступа)
* `POST /api/pleas/` — Создание новой заявки
* `PATCH /api/pleas/{id}/` — Изменение статуса заявки диспетчером/мастером
* `GET /api/pleas/stats/` — Статистика для дашборда диспетчера (новые, в работе, завершенные)
* `GET /api/news/` — Список новостей дома
* `POST /api/news/` — Публикация новости диспетчером
